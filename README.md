## Contents

This repo contains my Part A submission: 5 Bash scripts covering core
shell scripting concepts.

- `Bash_prog/Task1_file_handling.sh` — file handling basics (create, write, append, read, backup, delete)
- `Bash_prog/Task2_permissions_sudo.sh` — file permissions, chmod, and conditional chown with sudo
- `Bash_prog/Task3_pipes_redirection.sh` — log generation, pipes, and text processing (grep, awk, sort, uniq)
- `Bash_prog/Task4_return_codes_error_handling.sh` — disciplined exit-code handling with a cleanup trap
- `Bash_prog/Task5_crud_app.sh` — menu-driven Todo List CRUD app

Each script supports `-h`/`--help` and includes input validation and error handling.

## Usage

```bash
chmod +x Bash_prog/Task1_file_handling.sh
./Bash_prog/Task1_file_handling.sh <target-directory>
```
